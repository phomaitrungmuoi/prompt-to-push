01Install

Three tools, three commands.

Pick your system once. Every command on the page follows.

1 / 3

Git

Saves every change as a commit you can review or undo.

install + introduce yourself
$ xcode-select --install
PS> winget install --id Git.Git -e --source winget
$ sudo apt install git
$ git config --global user.name "Your Name"
$ git config --global user.email "you@example.com"

Use the same email as your GitHub account.

2 / 3

GitHub CLI

Your repositories in the cloud, driven from the terminal.

install + check
$ brew install gh
PS> winget install --id GitHub.cli
$ sudo apt install gh
$ gh --version

First, create a free account at github.com.

3 / 3

Claude Code

An AI agent that reads, edits, runs and ships your code.

install + sign in
$ curl -fsSL https://claude.ai/install.sh | bash
PS> irm https://claude.ai/install.ps1 | iex
$ claude   # opens your browser to sign in

Needs a Claude Pro, Max, Team or Enterprise plan, or a Console account.

Install Git first: Claude Code on Windows runs commands through Git Bash.

02Connect

One login links Git to GitHub.

The GitHub CLI signs you in through your browser, keeps a secure token, and hands it to Git. After that, git push just works, for you and for Claude.

terminal
$ gh auth login
? Where do you use GitHub? GitHub.com
? Preferred protocol for Git operations? HTTPS
? Authenticate Git with your GitHub credentials? Yes
? How would you like to authenticate? Login with a web browser
✓ Logged in as your-username

$ gh auth status   # check it any time

What happens on every push

  1. git pushRun by you, or by Claude
  2. gh hands Git the tokenStored in your system keyring
  3. GitHub accepts the commitsNo password typed, or seen by Claude

03Permissions

Let Claude commit & push on its own.

Two small files in your project. One says what Claude may run. The other says when it should ship.

What it may run.claude/settings.json
json
{
  "permissions": {
    "allow": [
      "Bash(git status)",
      "Bash(git diff:*)",
      "Bash(git add:*)",
      "Bash(git commit:*)",
      "Bash(git push:*)"
    ],
    "deny": [
      "Bash(git push --force:*)",
      "Bash(git reset --hard:*)",
      "Read(./.env)"
    ]
  }
}
  • allowruns without asking
  • denyalways blocked, beats allow
  • :*any arguments
When it should shipCLAUDE.md
markdown
## Git workflow

- When a task is done and checks pass,
  commit and push without asking.
- Stage only the files you changed.
- Use Conventional Commits: feat:, fix:, docs:.
- Never force-push. Never commit secrets.

Claude reads CLAUDE.md at the start of every session. Run /init inside Claude Code to create one.

Prefer clicking? Type /permissions inside Claude Code, or answer “Yes, and don't ask again” the first time Claude asks to commit.
